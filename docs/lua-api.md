# Lua API reference

Generated by `crates/oni/build.rs` from `src/script.rs` and
`src/mission/commands.rs` on every build — don't edit; change the
comments there. How the two Lua surfaces work: `docs/lua.md`.

## Scenario functions

Globals a scenario (`--script file.lua`) can call. Types: `int`,
`number`, `string`, `bool`, `table`, `function`, `any`; `?` optional.

| Function | Description |
|---|---|
| `input(f: bool, b: bool)` | Holds (or lets go of) the forward / backward move keys (W / S) for the player. |
| `feet_offset()` | how far the player's posed body's lowest point (its parts' bounding spheres, arms left out) is above its location. |
| `hold_jump(on: bool)` | Holds (or lets go of) jump (a press, then held: the higher jump). |
| `hold_fire(on: bool)` | Holds (or lets go of) fire 1. |
| `turn_keys(l: bool, r: bool)` | Holds (or lets go of) the turn-left / turn-right keys (lying down: rolls up). |
| `action()` | Taps the action key for one tick (in a fight: taunt). |
| `strafe(l: bool, r: bool)` | Holds (or lets go of) the strafe keys (A / D sidestep). |
| `walk(on: bool)` | Holds (or lets go of) the walk modifier (CapsLock). |
| `crouch(on: bool)` | Holds (or lets go of) the crouch key. |
| `fire(n: int)` | Tap a fire button (1 = left mouse, 2 = right, 3 = middle by default): unarmed, these are punch / kick / crouch. |
| `crouch_tap()` | Taps crouch for one tick (unarmed: the crouch attack button). |
| `faithful(on: bool?)` | Switches reproducing the original's known bugs (`docs/deviations.md`) on or off (omitted: left as is) → whether it is on now. |
| `seed(n: int)` | Reseeds every fighter's weighted animation pick, for repeatable runs. |
| `present(id: int)` | Whether fighter `id` is still in the level (not removed). |
| `damage(id: int, n: int, dx: number?, dz: number?)` | Deals damage to fighter `id` (no reaction unless it dies), with a small shove along (dx, dz) if given — the blow's way, attacker to it. |
| `lift(id: int, by: int, ticks: int)` | fighter `id` is lifted toward `by` as a weapon's "picked up" damage does, for `ticks` (at most 60). |
| `set_hp(id: int, v: int)` | Test hook: sets fighter `id`'s hit points outright (no reaction). |
| `patrol(id: int, points: table, pace: string?, looping: bool?)` | AI: walk fighter `id` along `points` ({{x, z}, …}) at `pace` ("run", "walk" or "creep"), optionally looping; `route_done(id)` reads progress. |
| `ai_order(id: int, dir: string, pace: string?, face: number?)` | AI: hold fixed orders — direction "forward" \| "backpedal" \| "left" \| "right" \| "stop", pace "run" \| "walk" \| "creep", optional facing (deg). |
| `spar(id: int, target: int)` | AI: make fighter `id` fight fighter `target` (a sparring partner). |
| `route_done(id: int)` | Whether fighter `id` has finished its `patrol` route (true too when it has none). |
| `set_facing(id: int, deg: number)` | Test hook: turn any fighter to an absolute yaw (body and target). |
| `knock(id: int, kind: int)` | Test hook: force a reaction (e.g. a knockdown) on any fighter. |
| `type_of(id: int)` | Fighter `id`'s current animation type number (0: no such fighter). |
| `state_of(id: int)` | Fighter `id`'s body state number (the current clip's end state; 0: no such fighter). |
| `temp_path(name: string)` | a path in the temp folder of this process's own (`oni_<pid>_<name>`): for a screenshot a scenario reads back, which a copy running at once (the fixed and faithful passes) mustn't share. |
| `image_mean(path: string, x0: number, y0: number, x1: number, y1: number)` | r, g, b (0–1): a saved screenshot's mean colour over a region (fractions of its width and height). |
| `fog()` | r, g, b, start, end: the fog now (screen depth: −1 near, 1 far). |
| `jello_objects()` | {name, …}: the placed objects see-through this tick (in the camera's way). |
| `jello_doors()` | {quads, leaves}: how many of the see-through quads this tick are closed doors' own (their "gunk"), and the leaves of open or moving doors see-through as objects ("door id:leaf"). |
| `object_in_way(ax: number, ay: number, az: number, bx: number, by: number, bz: number)` | whether the segment between the points meets an animating object (a placed object, an open or moving door's leaf: `AMrRayToObject`, as a lens flare's test asks). |
| `overall_volume()` | the sound's overall volume now (0–1). |
| `pause_toggle()` | F1 (the pause screen opened, or closed once up a second). |
| `pause_screen()` | The pause screen → {tab, page (from 1), pages, lines, hint, previous, next}, or nil when it is not up. |
| `cheats(on: bool)` | typing the cheat codes allowed (as once the game is won). |
| `type_keys(s: string)` | Types the letters of `s` on the pause screen (cheat codes) → the message the last finished code shows, or nil. |
| `effects(id: int)` | {shield, shield_shown, shield_active, shield_parts, daodan, invisibility, invisible_for, invis_active, invis_alpha, seen}: a fighter's shield and invisibility (`seen`: the AI can see it). |
| `frame_ticks(n: int)` | the ticks a frame runs with n passed on the clock (at most 6, plus any the clock is behind). |
| `time_scale()` | How much slower than the clock the game runs: 2 in slow motion, else 1. |
| `env_shade_of(r: int)` | The flat shade `env_shade` put on level part `r` (its script reference) → {r, g, b} (0–1), or nil. |
| `door_shade_of(id: int)` | {r, g, b}: the door's flat shade (0–1). |
| `door_ids()` | {object id, …}: the level's doors. |
| `obj_shades()` | Each live placed object's flat shade, in order: {r, g, b} (0–1), or false for none. |
| `boss_of(id: int)` | a boss's mode now ("ShootBeam", "Regenerate", …) or nil. |
| `magic_drawn()` | how many magic effects the last screenshot drew (shields, invisibility's shimmer). |
| `pause_press(button: string)` | Clicks a pause-screen button: "objective", "items", "weapons", "diary", "help", "previous", "next" or "close" (errors on any other). |
| `text_console()` | {name, page, pages, last, lines, button} or nil: the data console showing its text (page from 1; lines: the page's strings; button: its Next / Close button's {x, y, w, h} on a 640 × 480 screen). |
| `text_console_key(key: string)` | Presses a key on the data console's text: "next" (Space) turns the page; anything else (Esc) closes it. |
| `text_console_click(x: number, y: number)` | Clicks the left button at screen x, y (640 × 480) on the data console's text → whether it was on its Next / Close button. |
| `lock_of(id: int)` | the frames fighter `id`'s scripted animation still holds it (`animationLockFrames`; 0: free). |
| `facing_of(id: int)` | Fighter `id`'s body yaw (degrees; 0: no such fighter). |
| `dead(id: int)` | Whether fighter `id` is dying or dead (false: no such fighter). |
| `state()` | The player's body state number (`state_of(0)`). |
| `anim_type()` | The player's current animation type number (`type_of(0)`). |
| `jump()` | Queue a jump (fires on the next grounded tick); `airborne()` reads state. |
| `airborne()` | Whether the player is in the air. |
| `punch()` | Melee: queue a punch / kick (fires on the next step's first tick). |
| `kick()` | Queues a kick (fires on the next step's first tick). |
| `facing(deg: number)` | Snaps the player's body (and its facing target) to an absolute yaw (degrees). |
| `turn(delta: number)` | Nudges the player's facing target by `delta` degrees; the body slews toward it over the next ticks (as the mouse turns). |
| `facing_deg()` | The player's body yaw (degrees). |
| `aim_deg()` | The aim direction: where the player points, without the body lean a diagonal run or turned sidestep adds. |
| `desired_deg()` | The player's facing target yaw (degrees), which the body slews toward. |
| `spawn(x: number, y: number, z: number, facing_deg: number?, class: string?)` | Spawn a training dummy; returns its fighter id. |
| `place(name: string)` | Goals: places one of the level's characters by name (its class, position, job, alerts, profiles) → its fighter id; errors if the level places no such character. |
| `mission_begin(run: bool?, save_point: int?)` | The level's own scripts (`docs/lua.md`): begins the level (the player at its placement, the characters present from the start, `main`). `run` false: the scripts loaded but the level's start not run; `save_point` n: begun from the level's save point n. |
| `world_stats()` | what the world holds, for finding a runaway: live particles (and the busiest classes), weapons, fighters, corpses. |
| `laser_eyes()` | {{x, y, z}, …}: where the laser triggers' emitter eyes are drawn (#78). |
| `mission_info()` | What the level scripts are doing → {tasks, waiting = {…}, errors = {…}, objective, outcome, spawned, messages = {…}, stubbed = {command, …}}; an empty table before `mission_begin`. |
| `named(name: string)` | The fighter id of the live scripted character called `name` (its `chr_create` name; case matters), or nil. |
| `play_film(id: int, name: string, mode: string?)` | Plays a level film on fighter `id` (mode "", "fromhere", "interp"); returns its length in ticks, or nil. |
| `alarm(id: int, console: int?)` | Sends an AI to raise the alarm at console `console` (nil: the nearest). |
| `console_reset(id: int)` | Resets a console (unused; active as authored). |
| `collisions(id: int)` | walls, objects, characters, records, serious: what fighter id's movement met last tick, and its AI's collision records. |
| `objects()` | {{name, at={x,y,z}, frame, animating}, …}: the live placed objects. |
| `door_obstruction(id: int)` | {{x1, y1, z1, x2, y2, z2}, …}: where door id's leaves stand in the way of a path (each one's base edge at the end of its move; none for a leaf opening upward). |
| `door_leaves(id: int)` | {{at={x,y,z}, half={x,y,z}, solid, paused}, …}: door id's leaf boxes this tick. |
| `door(id: int, what: string)` | Orders door `id`: "open", "close", "lock", "unlock", "jam", "unjam". |
| `give_weapon(id: int, class: string)` | Weapons: puts a new gun of `class` in fighter `id`'s hand (the one it held is deleted, as `chr_giveweapon`) → whether it did (false: no such fighter or class). |
| `weapon(id: int)` | The gun in fighter `id`'s hand → class, ammo, firing, chamber (the ticks till it can fire again); all nil unarmed. |
| `aim(id: int, pitch: number)` | Sets fighter `id`'s aim pitch (radians, up positive). |
| `hud()` | The HUD: the lines in its message area, subtitles and console strip; the objective (and whether it is unread); the compass target; the letterbox's depth; the fade's opacity; the elements filled and flashing; the rings shown; the player's hit ring. |
| `game()` | The game flow: the level's outcome (true won, false lost), a splash screen asked for, the save point kept. |
| `lens_flares()` | Lens flares: how many there are, and how many are shown now . |
| `flares_behind_characters(on: bool)` | the option (#58) for this run's frames — characters hide the lens flares behind them. |
| `lens_flare_near(x: number, y: number, z: number)` | the opacity share now of the lens flare nearest that point (0 hidden, 1 fully seen). |
| `use_hypo(id: int)` | whether fighter `id` used a hypo (as Tab does). |
| `hypo_left(id: int)` | The health fighter `id`'s hypo still has to give (0: none, or no such fighter). |
| `read_objective()` | The player reads the objective (F1). |
| `subtitles(on: bool)` | Dialogue subtitles on or off (the game's option). |
| `hud_help()` | Whether the HUD's help overlay shows (the pause screen's Help page, ui_show_help). |
| `hud_triangles()` | How many overlay triangles the HUD draws now (on a 640 × 480 screen). |
| `camera()` | The game camera → x, y, z (where it is), vx, vy, vz (which way it looks), busy (whether a script waits on it). |
| `jello()` | How many level quads are see-through (jello) for the camera this tick. |
| `look_mode(on: bool)` | Holds (or lets go of) the look-mode key. |
| `aim_lr(v: number?)` | The player's look-mode turn (radians). |
| `aim_of(id: int)` | Fighter `id`'s aim pitch (radians, up positive; 0: no such fighter). |
| `reload(id: int)` | Fighter `id` starts reloading its gun (`WPrTryReload`) → whether it did (refused when full, busy, just fired, or out of clips). |
| `drop_weapon(id: int, knock: bool?)` | Fighter `id` lets go of the gun in its hand (`knock`: thrown clear, as a knockdown does). |
| `give_ammo(id: int, clips: int, cells: int?)` | Adds `clips` ammo clips and `cells` energy cells to fighter `id`'s inventory (no carry limit). |
| `corpses()` | {{class, x, y, z, drawn, dynamic}, …}: the level's corpses (its own, then the dead of play), where each one's pelvis is, and whether it is drawn (has a model, not cleared). |
| `shots()` | How many particles are alive (shots and every other effect). |
| `swap()` | Taps the swap-weapon key for one tick (holster / draw). |
| `spawn_weapon(class: string, x: number, y: number, z: number, falling: bool?)` | Puts a new gun of `class` at a point (falling: with physics, else resting as placed) → whether the class exists. |
| `loose_guns()` | {{class, at={x,y,z}, moving}, …}: the guns no one holds (moving: still sliding or falling). |
| `holster_of(id: int)` | The class of the gun fighter `id` has holstered, or nil. |
| `sounds()` | Sound: sounds() → the playing ambients, each {name, stage ("in", "body", "stopping", "out"), clip (the sound playing now), left, right (gains)}. |
| `impulse(name: string, x: number?, y: number?, z: number?, volume: number?)` | impulse(name [, x, y, z [, volume]]) plays an impulse sound (placed, or not) → its channel (0–15) or nil. |
| `channels()` | The 16 sound channels → each {clip, locked, volume (linear), left, right (output gains)}. |
| `sound_objects()` | the level's sound objects, each {ambient, x, y, z, box (else a sphere), state ("Off", "Starting", "Playing", "Stopping"), volume, playing}. |
| `sound_volume(v: number)` | Sets the overall sound volume to head for (0–1). |
| `powerup(id: int, kind: string, amount: int?)` | powerup(id, kind [, amount]) gives a powerup the game's way (`ammo`, `cell`, `hypo`, `shield`, `invis`, `lsi`) → how much it took. |
| `env_particles(tag: string)` | how many of the level's environmental particles tagged `tag` are alive. |
| `decals(class: string?)` | { {class, static, alpha, vertices, triangles, positions = {{x,y,z}…}, quad}, … }: the live decals (of a class), static first, oldest first. |
| `health_shade(id: int)` | the colour of a fighter's health (melee flashes' tint). |
| `particles_of(class: string)` | { {x, y, z, dx, dy, dz [, tint]}, … }: where each live particle of a class is, its forward (Y) axis, and its colour when that is a variable. |
| `animated_textures()` | {{name, frame}, …}: the animated textures the level and its models draw, and the frame each shows at the game time (as of the last screenshot). |
| `particle_textures(class: string)` | {file stem, …}: the texture each live particle of a class shows now (an animated one's current frame). |
| `shadow(id: int)` | {alpha, quad, vertices, positions} or nil: fighter `id`'s shadow this frame (and the quad it was placed by). |
| `bone(id: int, k: int)` | Fighter `id`'s posed bone k in world space → {x={…}, y={…}, z={…}, at={…}} (axes and position); nil: no such fighter or bone. |
| `held_gun(id: int)` | The gun in fighter `id`'s hand, as `bone` → {x, y, z, at}; nil unarmed. |
| `sight(id: int)` | {from, to, target, laser, tunnel}: fighter id's gun sight this tick (nil without one); target "none" \| "environment" \| "object" \| "character", laser its {r, g, b} (nil without one), tunnel how many sprites. |
| `gun_through_wall(id: int)` | Whether fighter `id`'s gun pokes through a wall (`ONrCharacter_IsGunThroughWall`): such a gun neither fires nor shows its sight. |
| `show_decals(on: bool)` | whether screenshots draw the decals (to compare). |
| `jello_drawn()` | how many see-through (jello) triangles the last screenshot drew, and how many of them were doors'. |
| `decals_drawn(x: number, y: number, z: number)` | {{quad, alpha}, …}: the decals drawn from that eye this frame (alpha 0..1, as drawn). |
| `set_jello(q: int, on: bool)` | marks a level quad see-through or not, as the camera does (until the camera's next update clears its own). |
| `ray(x1: number, y1: number, z1: number, x2: number, y2: number, z2: number)` | the first level quad between two points (any flags): {quad, at={x,y,z}, flags, object_tag, jello} — jello: it is see-through for the camera now; nil if nothing is in the way. |
| `quad_plane(q: int)` | Level quad `q`'s plane → a, b, c (its normal), d. |
| `particle(tag: string, command: string, event: string?)` | Sends the environmental particles tagged `tag` a command, as the BSL `particle` does ("create", "kill", "reset", "do" with `event`, or an event name) → false for an unknown command. |
| `console_screen(id: int)` | the texture console `id`'s screen shows now (by its state), or nil. |
| `dialog()` | whether a scripted dialogue line is on. |
| `sounds_playing()` | {name, …}: the sounds playing now, in start order. |
| `saying(id: int)` | the line a character is saying (an ambient's name) or nil. |
| `turret(id: int, what: string)` | Turrets: orders the turrets with script id `id`: "activate", "deactivate" or "reset". |
| `turret_state(id: int)` | The first turret with script id `id` → {active, yaw, pitch (degrees), target, firing, shots, idle_effect}, or nil: none. |
| `dodge_of(id: int)` | Agent `id`'s dodge → dx, dz (the way it dodges; nil: not dodging), weight (how strongly), projectiles (how many of the dangers are projectiles). |
| `gun_chance(id: int, percent: int)` | Sets agent `id`'s chance (percent) of going for a gun when it has none. |
| `running_pickup_chance(id: int, percent: int)` | its chance of picking a gun up on the run (`gun_runningpickup_percentage`). |
| `env_show(r: int, on: bool)` | Shows or hides level part `r` (`env_show`): drawn, solid and blocking sight only while shown; hiding glass breaks it. |
| `env_broken(from: int, to: int?)` | How many of the script references `from..=to` (`to` defaults to `from`) have no unbroken glass pane left (`env_broken`). |
| `inventory(id: int)` | Fighter `id`'s inventory → ammo clips, energy cells, hypos (0s: no such fighter). |
| `powerups_lying()` | How many powerups lie about the level. |
| `powerups()` | {{kind, at={x,y,z}, falling}, …}: the powerups lying about (falling: still with physics). |
| `weapons_lying()` | How many guns no one holds. |
| `laser(id: int, what: string, factor: number?)` | Orders laser trigger `id` ("activate", "deactivate", "reset", "hide", "show", "speed" with a factor). |
| `laser_state(id: int)` | Laser trigger `id` → active, on, triggered, and how many beams are out (all nil: no such laser). |
| `beams()` | Laser beams out now: a list of {x1, y1, z1, x2, y2, z2}. |
| `door_state(id: int)` | A door's state ("closed" / "opening" / "open" / "closing") and whether it is locked (nil: no such door). |
| `console_state(id: int)` | A console's state: "inactive", "active" or "triggered" (nil: none). |
| `teleport(id: int, x: number, y: number, z: number)` | Moves fighter `id` (feet) to a point. |
| `mission_exec(code: string)` | Defines script functions of the scenario's own (translated-Lua form) in the running mission, to call with mission_call. |
| `mission_call(name: string, arg: string?)` | Starts level-script function `name` as a new task (with one string argument, if given) → whether it exists (false without a mission). |
| `goals(id: int)` | Gives fighter `id` the default goals (idle, its class's combat profile). |
| `skip_cutscene()` | Asks to skip the cutscene (as Space does). |
| `cutscene_skip()` | The cutscene skip → mode ("idle" / "starting" / "black" / "skipping" / "fading in") and the screen's black (0–1; nil: none). |
| `player_ready()` | whether the player is in play: no cutscene, input on, no environment animation or film moving her, alive. |
| `set_gamma(v: number)` | the gamma option for frames drawn (0–1; 0.5 as drawn). |
| `menu_open(in_game: bool?)` | The main menu: brings it up (`in_game`: the in-game menu, with Resume); screenshots then draw it. |
| `menu_close()` | Takes the main menu down. |
| `menu_state()` | The menu dialog on top → {dialog, depth, rows, selected, visible = {id = title}, checks = {id = on}, sliders = {id = value}, popups = {id = item}}, or nil when none is up. |
| `menu_click(id: int)` | Clicks control `id` of the menu dialog on top (near its middle) → what the menu asks for ("new_game", "new_game faithful", "load L S", "resume", "quit", "options"), or nil; errors if the control isn't showing. |
| `menu_press(id: int, f: number)` | the left button down on control `id`, a fraction `f` of the way across it (held, for menu_timer / menu_release) → what the menu asks for, as menu_click. |
| `menu_timer(n: int)` | Fires the menu's timer `n` times (200 ms each) while `menu_press` holds the button, so a held slider steps on → what the menu asks for, as menu_click. |
| `menu_release()` | Lets go of the button `menu_press` held → what the menu asks for, as menu_click (nil: nothing held). |
| `menu_loading(percent: int?)` | the level-load dialog alone over black, its bar at `percent` (screenshots draw it); menu_loading() hides it. |
| `menu_key(name: string)` | Presses a key on the menu: "enter", "escape", "up", "down", "left", "right", "home", "end", "pageup", "pagedown" → what the menu asks for, as menu_click. |
| `look_at(id: int, x: number?, y: number?, z: number?)` | an agent looks at a point (as `ai2_lookatme`); look_at(id): it stops looking. |
| `aim_off(id: int)` | its aim off the body, left-right and up-down (degrees). |
| `eye_of(id: int)` | Where an agent's eyes look (degrees; nil: along its body). |
| `cinematics()` | the cutscene inserts showing: a list of {name, x, y, w, h} (top left and size on the 1024 × 768 virtual screen). |
| `overlays_of(id: int)` | the partial-body clips playing on fighter id: a list of {slot = "recoil" \| "inventory" \| "hit", clip, type, frame}. |
| `timer()` | (what it shows now or nil, ticks left, mode "on" \| "fail"), or nil with no countdown running (`world/timer.rs`). |
| `passive_of(id: int)` | whether fighter id's AI is passive (`ai2_passive`, a cutscene); nil: no such fighter. |
| `script_id_of(id: int)` | The id the level scripts know fighter `id` by: the player 0, a `chr_create`d character its setup's; nil for the rest. |
| `goal_of(id: int)` | What fighter `id`'s AI is doing, as one line ("job idle", "pursuit …", …); "other" for a test brain, "none" without one. |
| `neutral_of(id: int)` | fighter id's neutral interaction: {behavior (id), with (whom it talks with), line (0-based, nil before the conversation), accepted, begun, items_given, completed, resume_at} — nil without a behaviour or an interaction. |
| `probe(id: int, deg: number, dist: number)` | Looks along the floor from fighter `id` toward yaw `deg` up to `dist`: the free distance before a wall, and the distance to a ledge (or nil). |
| `nav_probe(id: int, deg: number, dist: number)` | Fighter `id`'s AI local probe along the floor toward yaw `deg` up to `dist` (the level's grids, obstructions counted, as its local movement sees them) → how far it is free, and the square it stopped at (nil: it got all the way). |
| `go_to(id: int, x: number, y: number, z: number, pace: string?)` | Navigation: fighter `id` walks (pace "run" / "walk") to a point through the level, pathfinding; nav_state(id) reads its progress. A new point while walking may keep the path (within 90 ticks, 20 of the last). |
| `nav_path(id: int)` | The waypoints fighter `id` is following (`go_to` or an agent's) → {{x, z, radius, next}, …} (next: the one it heads for); empty without a path. |
| `nav_legs(id: int)` | Fighter `id`'s path through the rooms → the room it is in along it (0: the first), how many rooms it passes, and when it was planned; nil without one. |
| `nav_state(id: int)` | Fighter `id`'s navigation → "planning", "following", "arrived", "failed: …", or "none". |
| `nav_obstruction(x: number, y: number, z: number, asker: int?)` | What the pathfinding grid has stamped at (`x`, `y`, `z`) → "character", "object" or "door", its index (fighter, object, door), and whether it blocks fighter `asker` (default 1) planning a path; nil if nothing. |
| `melee_plan_of(id: int)` | The class fighter `id`'s melee techniques are planned with (its profile's `char_classname`), or nil: none (its own class, or no profile). |
| `watch(id: int)` | Perception: makes fighter `id` an AI that watches and listens (not a passive dummy). |

## Engine commands for level scripts

What the translated BSL calls as `C.name(…)` (`docs/lua.md`). Names
starting with `@` are the prelude's own hooks. Commands not listed
are logged once and do nothing.

| Command | Description |
|---|---|
| `@word` | An engine variable's value, a value command's result, or nil (the word stands for itself). |
| `@chr_at` | (For our fixes, `fixes/`: where a character stands, feet — the player by default; nil if it isn't present.) |
| `@ticks` | A `sleep` argument (`SLEEP`) as ticks: a number as is, a word by its value (0 if none); never negative. |
| `@fork`, `@adopt` | Runs a coroutine as a new task (`@adopt`: one the prelude already started and that yielded) after `delay` ticks, labelled for `mission_info()`.waiting. (No prelude code sends `@fork` now.) |
